# Ectopia

**Whitepaper, October 2019.** A decentralized, self-sustainable ecosystem for building secure,
sustainable and inclusive habitats.

📄 **[Read the whitepaper →](whitepaper_v1.md)**

It has served as the blueprint for what came after, built step by step:
[Tenzro](https://github.com/tenzro) the network, [Furcate](https://github.com/furcateai) the
intelligence, [Furcate OS](https://github.com/furcateresearch) the operating system (successor to Sovox),
[Living Worlds](https://livingworldslab.com) the simulated worlds, and now
Recursive Self.
